A Chrome extension that uses Google's Gemini to intelligently summarize WhatsApp group conversations directly from WhatsApp Web. It extracts recent messages (50/100/200/300), sends them to Gemini for analysis, and returns concise summaries with key points.

Key features include an intuitive popup UI, one-click summarization, real-time progress, copy/save to local history, multi-language support (summarize any language, output in English), and privacy-first local processing with no tracking.

Get the source code and instructions on GitHub.
